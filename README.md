A square, screen-printed travel poster for Koravel, an inland city built into a wind-sounding bell. Its lantern causeway leads into the warm guest halls carved inside the landmark.

## Run it

```sh
python3 main.py
```

The entrypoint uses only the Python standard library and copies the committed poster to `/output/entry.png`.

`render_poster.py` regenerates `poster.png` during development; that optional step requires Pillow and DejaVu Serif Condensed. The grader does not run the renderer.
